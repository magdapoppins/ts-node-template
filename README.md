# TypeScript Node API Starter Kit

A minimal TypeScript API starter for Node.js.

### Tools used

- [Fastify](https://fastify.dev/) for the API
- [TypeScript](https://www.typescriptlang.org/) for type checking and compilation
- [tsx](https://tsx.is/) for development watch mode

### How-to

1. Install Node.js and npm.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the API on port 8080.
4. Visit `http://localhost:8080/status` to get `{ "status": "ok" }`.
5. Run `npm run build` to compile the project, then `npm start` to run it.

Set the `PORT` environment variable to use a different port.
